# Rebuild Engine

GameMaker 스타일 Object/Event 구조를 목표로 만든 Python + Pygame 기반 2D 엔진/에디터입니다.

## 에디터

`python editor.py` 로 프로젝트 매니저를 열고 프로젝트를 선택합니다.

### 현재 UI 구성

에디터는 다음 구조로 배치되어 있습니다.

- 왼쪽 위 **리소스**: 오브젝트 / 스프라이트 / 음악 / 씬 목록을 탭으로 전환
- 왼쪽 아래 **이벤트**: 선택한 Object의 Create / Step / Draw 등의 이벤트
- 가운데 위 **씬 보는곳**: Scene 배치·선택·이동
- 가운데 아래 **코드 / 출력**: 선택한 이벤트의 Rea 코드
- 오른쪽 **인스펙터**: Object / Instance 속성

씬은 별도 탭이 아니라 **리소스 → 씬** 목록에서 바로 선택해서 전환합니다.

### 이미지
`이미지` 버튼으로 PNG/JPG/BMP/GIF를 프로젝트 `assets/`로 복사합니다.

### 스프라이트 애니메이션
`애니메이션` 버튼 → 스프라이트 시트 선택 →
애니메이션 이름, 프레임 너비/높이, FPS를 입력합니다.
생성된 리소스는 `assets/animations/*.anim.json`으로 저장되며 여러 프레임을 자동으로 잘라서 재생합니다.

애니메이션 Sprite를 Object/Instance에 연결하면 기본 재생 속도도 자동으로 설정됩니다.

### 음악
`음악` 버튼으로 OGG/WAV/MP3/FLAC 등 오디오 파일을 `assets/audio/`로 가져옵니다.
왼쪽 MUSIC 목록을 클릭하면 에디터에서 미리듣기할 수 있습니다.

Rea 코드에서는 다음 내장 함수를 사용할 수 있습니다.

```rea
음악_재생("audio/bgm.ogg")
음악_정지()
음악_볼륨(0.5)
```

## 성능

에디터 리소스의 이미지 썸네일과 Rea 코드 렌더링을 캐시하고, 씬/음악/이미지 파일 목록은 매 프레임 파일 시스템을 다시 읽지 않도록 구성했습니다.
